ABOUT THE PROJECT

script-vm-next 是什么？

script-vm-next 是一个基于寄存器的 JavaScript 虚拟化编译器，将源代码转换为字节码和自包含的 JavaScript 解释器。这个在线 Playground 展示单文件脚本从编译到运行的过程，支持查看和下载生成的 IIFE 产物。

浏览器本地编译

在本地 Worker 中处理源码，无需把代码上传到编译服务器。选择内置示例或输入自己的 JavaScript，即可查看结果。

按需生成 VM

默认 auto 模式分析所有已编译函数，仅组装所需的指令和辅助函数，减少简单程序的产物体积。

可检查的编译产物

查看字节码长度、产物大小和执行方式，复制或下载代码，在自己的 JavaScript 宿主中验证运行行为。

如何使用这个 JavaScript Playground

  1. 选择示例，或在源码区输入单文件 JavaScript。
  2. 点击「编译」，查看生成代码、产物大小和按需运行时统计。
  3. 点击「运行产物」查看日志，或复制、下载代码用于本地验证。

项目当前覆盖经过测试的 JavaScript 子集，尚不宣称完整符合 ES2015/ES6。浏览器 Demo 与 Node.js 文件 API 的模块能力不同，接入前请阅读兼容性说明。

A JavaScript bytecode compiler in your browser

script-vm-next compiles a tested JavaScript subset into register-based bytecode and a self-contained interpreter. This playground compiles standalone scripts locally, assembles the required VM at compile time, and lets you inspect, download, and run IIFE output. See the documentation for language and module limits.

QUESTIONS & ANSWERS

常见问题

script-vm-next 会把源码上传到服务器吗？

演示页在浏览器本地 Worker 中完成编译，不会把源码上传到编译服务器。只有你点击「运行产物」时才执行程序。

为什么只写 console.log，生成的代码里也有 VM？

编译产物包含字节码和执行这些字节码所需的解释器。默认 auto 模式会分析所有已编译函数，保留所需的指令、执行方式和辅助函数，为简单程序生成所需的 VM 子集。

这个 Demo 支持哪些 JavaScript 和模块语法？

演示页接受单文件脚本，提供闭包、类、迭代器与异步函数等示例。它不支持模块导入导出、require、动态 import() 或 DOM；项目当前覆盖经过测试的 JavaScript 子集，具体语法和语义边界见兼容性矩阵。

下载的编译产物也处于沙箱中吗？

下载产物使用运行宿主的全局对象与权限，本身不提供安全沙箱。Demo 的执行限制由页面单独提供：程序运行在隔离 Worker 中，禁用网络和 DOM，并有超时与日志上限。

现在可以通过 npm 安装 script-vm-next 吗？

当前目标版本为 0.2.0-beta.1，npm 包尚未发布。你可以从 GitHub 获取源码，按照 README 本地构建并验证安装包；以仓库发布状态为准。
